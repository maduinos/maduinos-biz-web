FPGA 외주 개발
설계부터 보드 검증까지

Verilog/SystemVerilog RTL, 고속 센서 인터페이스, Zynq/MPSoC 시스템 개발을 지원합니다. 신규 설계와 기존 보드의 기능 추가·디버깅을 프로젝트 조건에 맞춰 진행합니다.

Development Scope

필요한 기능부터 시스템 통합까지

FPGA 설계 용역, IP 개발, 펌웨어 연동과 보드 Bring-Up 중 필요한 업무를 협의합니다.

RTL·FPGA IP 개발

Verilog/SystemVerilog 기반 제어 로직, FSM, FIFO, 레지스터와 커스텀 IP를 설계합니다.

센서·고속 인터페이스

CIS 라인스캔, LVDS 입력, 타이밍 캡처, 데이터 정렬과 버퍼링을 구현합니다.

Zynq / MPSoC 통합

PS/PL 구조, AXI·DMA·DDR 데이터 경로와 Baremetal·RTOS·Linux 펌웨어 연동을 다룹니다.

시뮬레이션·설계 검토

테스트벤치와 파형으로 기능을 확인하고 클럭·리셋·CDC, 타이밍과 리소스를 검토합니다.

고객 보드 Bring-Up

부팅, 클럭·리셋과 인터페이스 초기 구동을 확인하고 실측 기반으로 문제를 추적합니다.

기존 설계 개선

기능 추가, 데이터 경로 병목과 타이밍 문제를 분석하고 수정 범위와 검증 조건을 제안합니다.

Questions

외주 개발 문의 전 확인하세요.

일부 기능만 의뢰할 수 있나요?

RTL 모듈, AXI IP, 센서 인터페이스 등 필요한 기능 단위로 범위를 상담할 수 있습니다.

이미 제작한 보드도 가능한가요?

기존 회로와 FPGA 프로젝트, 현재 증상을 검토한 뒤 Bring-Up·디버깅과 기능 추가 범위를 협의합니다.

어떤 자료가 필요한가요?

목표 기능, FPGA·보드 정보, 인터페이스, 처리량·지연시간과 희망 일정을 준비해 주세요. 초기 상담은 공개 가능한 요약으로 시작할 수 있습니다.
