FPGA/Zynq 센서 처리
기술 검토와 PoC

MADUINOS는 Camera, TDC, CIS 센서 입력을 FPGA/Zynq 기반 capture, timing, preprocessing 구조로 연결하는 기술을 개발합니다. 고객의 보드, 센서 조건, 실패 로그를 기준으로 data path와 검증 순서를 먼저 정리합니다. 교육/컨설팅과 임베디드 제품 PoC는 지금 바로 제공하고, ZM4 FPGA SoM 기반 센서 처리 플랫폼은 개발 중입니다.

ZM4 Platform

개발 중인 ZM4 플랫폼으로
센서 처리 모듈을 준비합니다.

ZM4 FPGA SoM은 MADUINOS의 Camera, TDC, CIS 기술을 검증하고 모듈화하기 위한 개발 중인 ZM4 플랫폼입니다. 현재 공개 메시지는 검증된 기술 구조와 개발 방향을 중심으로 두고, 상세 스펙은 확인된 항목부터 단계적으로 정리합니다.

ZM4는 제품화 전 단계의 기준 하드웨어입니다. 고객에게는 개발 상태를 명확히 공유하고, 교육, 기술 컨설팅, 임베디드 제품 PoC는 별도 서비스로 바로 제공 가능하게 운영합니다.
Target SpecificationFPGA SoM, sensor I/O, host control, validation kit 기준으로 정리
Module DirectionCamera / TDC / CIS 처리 모듈과 carrier 적용 흐름 준비
Validation Flowregister map, host CLI, CSV log, timing capture log로 검증
