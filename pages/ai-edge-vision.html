Core Blocks

보유 기술은 세 가지 센서 처리 축으로 설명합니다.

Camera capture

frame input, ROI, buffer, preprocessing, result overlay를 FPGA/Zynq data path에 연결합니다.

TDC timing

trigger, timestamp, histogram, timing capture log로 라이다, 초음파, 이벤트 시간을 검증합니다.

CIS sensor processing

line sensor, 조명 timing, raw capture, calibration, recognition preprocessing 흐름을 구성합니다.

Validation Package

결과는 화면보다 재현 가능한 로그와 자료로 남깁니다.

센서 처리 기술은 동작 영상만으로 판단하기 어렵습니다. MADUINOS는 입력 조건, register map, CSV log, timing capture log, validation report를 함께 정리합니다.
