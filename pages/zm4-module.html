Production Application

PoC에서 양산 적용 검토까지 같은 흐름으로 이어갑니다.

1. Quick Start

검증된 보드에서 boot, JTAG, UART, register access, host tool을 확인합니다.

2. First Sensor Data

고객 센서 입력을 ZM4 FPGA SoM data path에 연결하고 재현 가능한 로그를 남깁니다.

3. Carrier Definition

제품 조건에 맞는 connector, power, test point, mechanical 조건을 carrier 적용 범위로 정의합니다.

4. Production Review

PoC 결과, 리스크, 양산 적용 항목, 다음 개발 범위를 제품화 판단 자료로 정리합니다.
